# Assignment 2 — Mobile Computing (CO2)

Based on ITA03_Mobile_Computing_CO2_Assignment.docx. All seven question folders are organised separately. Each contains data/, figures/, a report, a Python program and requirements.txt.

| Folder | Topic |
|---|---|
| Q1 | Mobile Communication vs Mobile Computing — Field-Service Technology Audit |
| Q2 | FDMA vs TDMA under different traffic conditions |
| Q3 | CDMA — Orthogonality, Spreading and Near-Far Problem |
| Q4 | OFDMA — Subcarrier scheduling and fairness |
| Q5 | SDMA — Spatial reuse and array beamforming |
| Q6 | Choosing Multiple-Access Techniques for Real Deployments |
| Q7 | Diagnose, Redesign and Validate OFDMA user starvation |

Run a program from the repository root, for example: python Assignment2/Q1/q1.py. Install the requirements listed in that question folder first.

**Data provenance:** source-reported values are identified in the reports. Any illustrative ratings or intermediate comparison points are explicitly labelled; they are not presented as measured values from the DOCX.
