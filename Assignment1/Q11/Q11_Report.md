# Q11 — Recommend and Defend the Final Design

## Objective
Implement and evaluate the task described in CO1 Assignment 1.

## Method
The accompanying Python program creates a reproducible data table and a visualization for this task. Assumptions and any illustrative values are identified in the code and dataset.

## Execution
From the repository root:

```bash
pip install -r Assignment1/Q11/requirements.txt
python Assignment1/Q11/q11.py
```

## Output
The program writes CSV results to `data/` and a PNG chart to `figures/`.

## Discussion
Interpret the generated results in the context of the task. For Q9 and Q10, the included summary values are taken from the assignment's reported evidence where stated. For Q11 and Q12, qualitative scores and surge-load values are explicitly illustrative planning assumptions, not measured field results.
