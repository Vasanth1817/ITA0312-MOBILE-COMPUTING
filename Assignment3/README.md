# Assignment 3 — Mobile Computing (CO3)

Based on `Mobile_Computing_Assignment3_CO3.pdf`. All seven question folders are organised separately. Each contains a question report, runnable Python script, requirements, data/ and figures/ folders.

| Folder | Question |
|---|---|
| Q1 | Wireless Network Architecture and Mobility Analysis |
| Q2 | Mobile IP and Mobility Management |
| Q3 | Cellular Networks versus Ad Hoc Wireless Networks |
| Q4 | Applications of Mobile IP and Routing Requirements |
| Q5 | Proactive Routing Protocols in Mobile Networks (DSDV) |
| Q6 | Reactive Routing and DSDV–AODV Comparison |
| Q7 | Design a Mobile Emergency Communication Network |

Run from the repository root, for example: `pip install -r Assignment3/Q1/requirements.txt` then `python Assignment3/Q1/q1.py`.

**Data provenance:** reports distinguish model calculations and source-reported simulation values. CSV files include assignment data or explicitly stated simplified models; the scripts reproduce the listed calculations/plots and are not a full packet-level network simulator.
